\subsection{All of pglib-uc}
\label{sec:allpglib}

We then solved the LP relaxations of all 56 instances in pglib-uc with the same program, unchanged; 49 of these instances had played no part in building or checking it. The reference for this comparison is EGRET 0.6.2 with a pull request applied.\footnote{\url{https://github.com/grid-parity-exchange/Egret/pull/342}, commit \texttt{d684afd}.} Of the 56 LP bounds, 43 agree, with a largest difference of $8\times 10^{-6}$ on an objective near $10^8$. On the other 13 the program's bound is higher, by at most 0.008\%, and all of these come from the difference in (35) at $t=1$ described above: the program's row is valid and tighter, and a copy of the program using EGRET's row matches on all 56. A Claude Code session that could read EGRET's code made this comparison and the copy.

This check covers LP bounds only, so it does not test integer solutions. We also solved the MIP on those 13 instances, and the intervals from MIP bound to objective overlap. The original experiment used EGRET 0.6.2; rerunning against the version with this pull request gave the same LP bounds and overlapping MIP intervals on the seven instances.
